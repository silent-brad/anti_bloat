* Keybindings

Pinnacle keybindings are in =home/desktop/pinnacle/pinnacle_config.lua=.

** Adding a Keybinding

#+begin_src lua
bind("SUPER", "E", "exec", "emacs")
#+end_src

** Modifier Keys

| Modifier | Key |
|----------+-----|
| SUPER | Windows/Super key |
| SHIFT | Shift |
| CTRL | Control |
| ALT | Alt |

Combine with space: =SUPER SHIFT=, =CTRL ALT=

* Packages

** System Packages

Edit =hosts/common.nix= or host-specific =default.nix=:

#+begin_src nix
environment.systemPackages = with pkgs; [
  new-package
];
#+end_src

** User Packages

Edit =home/default.nix=:

#+begin_src nix
home.packages = with pkgs; [
  new-package
];
#+end_src

** Finding Packages

#+begin_src bash
# Search nixpkgs
nix search nixpkgs <package>

# Or use web search
# https://search.nixos.org/packages
#+end_src

* Neovim

** Adding Plugins

Edit =home/editors/neovim/lua/plugins/init.lua=:

#+begin_src lua
{
  "author/plugin-name",
  config = function()
    require("plugin-name").setup({})
  end,
}
#+end_src

** Keymaps

Add to =home/editors/neovim/lua/init.lua=:

#+begin_src lua
vim.keymap.set("n", "<leader>f", function()
  require("telescope.builtin").find_files()
end)
#+end_src

* Theming

2. Neovim: =home/editors/neovim/lua/plugins/init.lua= → colorscheme plugin

  nerd-fonts.fira-code

];
#+end_src

* EWW Bar

Configuration lives in =home/desktop/eww/=.

- =eww.yuck= — widget definitions and layout
- =eww.scss= — styling (Catppuccin Mocha theme)
- =scripts/= — polling scripts (memory, volume, network, battery, workspaces, openrouter)

** Adding a Widget

1. Add a =defpoll= variable in =eww.yuck= with a polling script
2. Add a =defwidget= to display it
3. Add the widget to the =left=, =center=, or =right= box
4. Add styling in =eww.scss=

* Window Rules (Pinnacle)

Window rules are configured in =home/desktop/pinnacle/pinnacle_config.lua=:

#+begin_src lua
Window.add_window_rule(function(window)
  window:set_decoration_mode("server_side")
end)
#+end_src

* Multiple Hosts

To add machine-specific overrides:

1. Create host config in =hosts/<hostname>/=
2. Import different hardware modules
3. Override settings as needed

Common settings stay in =hosts/common.nix=.
